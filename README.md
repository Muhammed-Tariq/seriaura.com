## Footnotes

Put a template inside a footnote marker after the words you want to annotate:

```html
<p>A sentence worth explaining<sup data-footnote><template>
  I'm using "ordinary quotes", <em>italics</em>, and <strong>bold</strong>.
  Here's a <a href="https://example.com">working link</a>.
</template></sup>.</p>
```

The note is ordinary HTML inside `<template>...</template>`, so apostrophes and double quotes in its text need no escaping. Formatting, links, paragraphs, and lists work as they do elsewhere on the page. Use `&lt;` to display a literal less-than sign and `&amp;` for a literal ampersand. The template stays hidden until its contents are shown in the popup.

On Home and information pages, `footnotes.js` numbers notes automatically in reading order. Hover over a number and move onto the box to read or click its links. Keyboard focus opens the note; Tab enters its links, Shift+Tab returns to the reference, and Escape closes it and returns focus from the popup to its number. On touchscreens, tap the number to open it and tap again or elsewhere to close it. External links open in a new tab, following the site's usual link behaviour. There is no footnotes section at the bottom. Existing footnote URLs still lead to the number in the text.

Articles additionally load `article-notes.js`: notes remain visible in the right margin above 1100px, with small orange numbers, muted text, and a fine left rule. Notes align with their references and move down to avoid one another; the article reserves room for the final note. Wider columns and a 1.55 line height improve longer notes, whose lengthy paragraphs are split at sentence boundaries without changing the text or inline links. All notes use upright text. Bars remain grey, fade to orange while a note or its reference is hovered, and fade back on exit; desktop references are not permanently styled as expanded disclosures. On smaller screens or a zoomed visual viewport, references use the same hover/focus/tap popups as Home; Escape and outside taps dismiss them. Backlinks return focus to the reference. Fonts, images, and viewport changes trigger a new layout. Run `node tools/verify-article-notes.cjs` to check note spacing, responsive disclosures, botanical symbols, pin placement, sidebar centring, and link colours. `node tools/verify-scroll-rendering.cjs` checks cached ribbon pixels, rapid scrolling, prepared photos, fixed navigation, and the gradient logo.

Use this markup in any collection or standalone page. Notes can be refreshed with the existing `collectionchange` event. Older plain-text `data-footnote="..."` attributes remain supported, but use the template form for new or formatted notes. All existing pages load `footnotes.css` and `footnotes.js`; include both when creating another page.

The “Josh-isms” link now opens `josh-isms/index.html`. Add its writing below the heading, where the HTML comment marks the space for content.

| Field | What to edit |
| --- | --- |
| `gallery` | `opening` for the main collage, or `closing` for the final pair of portraits |
| `x`, `y` | Legacy percentage positions; the desktop collage now uses `--collage-x` and `--collage-y` in `style.css`, while smaller screens use --compact-x/y in mediaqueries.css. |
| `width`, `height` | Outer frame size in design pixels; scaled automatically for the screen |
| `rotation` | Degrees; negative tilts left, positive tilts right |
| `crop` | Image focal point, e.g. `'50% 35%'` keeps more of the upper part visible |
| `cropBox` | `[left, top, width, height]` of the selected rectangle, as percentages of the original image; leave out for ordinary `crop` positioning |
| `layer` | Higher values place a frame above overlapping neighbours; group photos and SIRI LIFE use `2` |
| `quarterTurn` | Image-only rotation in quarter turns; `-1` turns the Liquicity tent photo upright counterclockwise. Use without `cropBox`. |
| `alt` | A short description for screen readers |

For example, to move the sunset photo right and down, find `[data-photo="sunset"]` in `style.css` and increase its `--collage-x` and `--collage-y`. To show more sky, add `crop: '50% 25%'` to its entry in `content.js`.

Rotated frame edges stay inside the preceding text’s margins, with the lower rows tucked upward to preserve ribbon clearance. `.polaroids` defines the 1430-unit canvas height and scales its coordinates at 68% of the page's design scale. Smaller-screen scaling is in `mediaqueries.css`.

The group photos use larger frames with crops that retain everyone. SIRI LIFE uses a 260 × 211 frame focused on the sheet. Dune is cropped to the tabletop to exclude feet.
